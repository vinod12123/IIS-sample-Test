2. Individual tests

An HTTP 500 or 404 is a successful test when the returned status matches the selected scenario. The plain 500 is intentional, not an unhandled crash.

Application errors

Unhandled exception and type mismatch are real ASP runtime errors: IIS records the error text in its access log. Database failure, Event log error and Upstream down also write an entry to the Windows Application event log (the response shows eventLogged).
